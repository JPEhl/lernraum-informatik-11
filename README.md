# Lernraum Informatik 11 – Schülerfassung

Hier liegt die jeweils neueste Fassung des Lernraums *Informatik 11* (Kapitel „Ein Spiel aus Text“).
Der Lernraum holt sie selbst: Kursseite ganz unten → **Nach neuer Fassung suchen**. Dein Stand und deine
Programme bleiben dabei, wie sie sind.

- `lernraum_i11.zip` – der ganze Lernraum (entpacken, dann `SO_FAENGST_DU_AN.pdf` lesen)
- `fassung.json` – Nummer, Datum, Änderungsliste und Prüfsumme der ZIP

Der Lernraum läuft nur auf dem eigenen Rechner (Thonny, Python ≥ 3.10); nichts davon verlässt den Rechner.
Schriften (Exo 2, Russo One, Teko) und der Editor (CodeMirror) stehen unter eigenen Lizenzen –
siehe `_system/seite/fonts/` und `_system/seite/codemirror/` in der ZIP.
